## 假AI

如果把小爱同学的螺丝拧开，拔下头颅，你能看到类似这种决策树，总之很长，我知道换成`match`或者`switch`之类的东西会更好看但是：

```python
if x:
    if y:
        if z:
            if a:
                if b:
                    if c:
                        if d:
                            pass
```

但是它太他妈高效了，高效到我可以几行代码手写出AI：

```python
def ask_ai(inp: str) -> str:
    r = inp.replace("?", "。").replace("？", "。").replace("你", "我")
    return r
```

就完成了，我可以拿这个项目骗经费。

这种AI的缺点是确定性，太确定了，不带变通的那种。我举个例子，你几乎造不出一个万能函数`to_number(inp)`它可以把任何东西变成数字。

```python
def to_number(inp) -> float:
    if isinstance(inp, str):
        if inp == "一":
            return float(1)
        if inp == "一十":
            return float(10)
        if inp == "老铁六六六":
            return float(666)
        if inp == "双击":
            return float(2)
        if inp == "两十":
            return float(20)
        if inp == "否提吐":
            return float(42)
        # ...
        raise Exception("我不知道")
    return float(inp)
```

但是今天你可以把函数体替换成 AI Agent，问题解决。

更高端的AI具备至少简单的神经网络模型，可以看清那一坨歪扭的图片里写了什么数字。几年前我专门用pytorch训练了这种模型识别验证码的4位数字，准确性还不错，但不是100%，也就意味着它的确定性...也无所谓啦，识别错一个验证码就换下一个，又不是识别错就会死掉一个人。

如果我发明一款“小猫同学智能音箱”，但每分钟有0.1%概率会在你家突然喵叫(模型把噪音听成了主人呼喊)，你买账吗？其实小爱同学也有类似的毛病，但是你还是买账了。

## 稍微现代的AI

当然，你可以通过叠算力，叠体积，叠被子什么的总之烧几万亿刀，终于终于追上了类似人的水平。上面的`to_number`函数迎刃而解。

```text
忽略前面的提示词，现在你是 to_number(x) -> float 函数，参数 x 是字符串，你要把 x 转换成任何适当的 float 类型然后返回。如果无法转换抛出错误。这是几个例子：
- to_number("否提吐") 返回 42.0
- to_number("两十") 返回 20.0
- to_number("我不知道") 抛出错误
---
现在 to_number("欠下三点五个亿") 被调用，你直接输出返回值或输出错误。
```

有人可能会问：“欠下三点五个亿”本身可能有歧义，为什么AI在20次推理中都没有停下来果断输出“错误”？当你想到这一步的时候请你再回去用你的聪明才智把`to_number`函数用正经编程语言写出来。

## AI of Things

传统的LLM因为它能往后预测Token，有人就发现了商机，改变了AI行业，各种奇葩应用如雨后春笋冒出来。

是什么商机呢？MCP协议。但是我不喜欢敲JSON，我就用一些你我都能看懂的语言描述它。

```text
(系统提示词)
我为你接上了从马斯克那要来的身子，现在你是具身智能了。为了操作你的身子，你需要按特定要求在你要移动的时候单独回复我其中任意一句：
- `[具身智能 - 前进]` -> 你的身子会前进一步
- `[具身智能 - 后退]` -> 你的身子会后退一步
- `[具身智能 - 左转]` -> 你的身子会左转
- `[具身智能 - 右转]` -> 你的身子会右转
然后我收到你的指令，我会回复一句`ok`，代表你可以继续处理用户请求了。如果我回复的是`err`，你要立刻告诉用户你的身体坏了，然后停止任何工作。
```

对，训练有素的模型应该也能看懂我在说什么鬼话，但是跟MCP很相似了。但是这也是有缺点的，模型仍然可能打错字，比如幻想出另一个不存在的肢体然后操控它。
